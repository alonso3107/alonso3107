## Proyectos

### [SATA](https://github.com/alonso3107/SATA) · gestión de trabajos de campo

`C#` `ASP.NET Core` `Angular` `PostgreSQL` `Podman`

Web interna para registrar trabajos de campo con evidencia fotográfica: el administrador crea y
asigna la orden, el técnico sube las fotos desde el celular, y al aprobarse se genera el PDF y se
entrega solo a Google Drive. Monolito modular con RBAC, auditoría de cada escritura y un asistente
LLM aislado —sin herramientas ni acceso a la base de datos—.

Más de 900 pruebas automatizadas, incluido un smoke E2E, y despliegue por tag con imágenes ARM64.

<sub>**MIT** · última versión `v3.0.0` · CI, deploy y release en GitHub Actions</sub>
